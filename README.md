# Карта маршрутов — зима 2026/27

Страница: https://zovminga.github.io/asia-2027/

Здесь лежит только готовая страница. Собирается она в отдельном проекте
скриптом `scripts/build_map.py`; правки вносятся там, сюда заливается
готовый `index.html` командой `python3 scripts/build_map.py --publish`.

Цены меняются каждый день. На странице стоит дата снимка — перед покупкой
проверяйте по ссылке на билет.
